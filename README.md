# Una nota para ti

Una página web que muestra un mensaje reconfortante cada vez que se abre, pensada para adolescentes y maestros. Hecha para pegar el enlace o un código QR en un salón de clases.

Funciona **con datos o sin conexión**: la primera vez que se abre guarda la página en el teléfono o la computadora. Después se puede seguir leyendo mensajes aunque no haya internet.

## ¿Qué hace?

- Muestra un mensaje corto y cálido al entrar, con estilo de nota de papel.
- Tres categorías: **para cualquiera**, **para estudiantes** y **para maestros/as**.
- Nunca repite un mensaje hasta haber mostrado todos los de esa categoría; luego vuelve a barajar.
- Botón "otro mensaje" para leer otro sin recargar la página.
- Lista para usar offline (PWA): fuentes, textos e interfaz van incluidos.

## Ver la página

🔗 https://s3ebaz.github.io/comfortant-message/

## Cómo usarlo

1. Abre el enlace o escanea el código QR **una vez con internet**.
2. Elige si quieres un mensaje general, para estudiantes o para maestros/as.
3. Toca "otro mensaje" para ver otro.
4. En el celular puedes usar *Agregar a pantalla de inicio*. La próxima vez abrirá aunque no haya señal.

## Publicarlo (GitHub Pages)

1. Sube estos archivos al repositorio (`index.html`, `sw.js`, `manifest.webmanifest`, `icons/icon.svg`).
2. Ve a **Settings → Pages**.
3. En "Build and deployment" elige **"Deploy from a branch"**, rama `main`, carpeta `/ (root)`.
4. Guarda y espera uno o dos minutos.
